# 生产上线清单

## 必须补齐

- **运营主体与联系方式**：公开主体名称、地址、客服/举报入口、数据保护联系人。
- **域名与备案**：在中国大陆提供互联网信息服务前，核实 ICP 备案、公安备案及适用许可；不要使用“政府平台”“官方认证”等无法证明的表述。
- **账户安全**：生产环境使用托管数据库、Argon2id/bcrypt、HTTPS、CSRF 防护、登录限流、刷新令牌轮换、RBAC、审计日志和备份恢复。
- **内容治理**：发布前审核、举报、下架、申诉、证据留存和管理员操作日志；项目/人才资料明确“平台仅撮合，不保证合作或收益”。
- **隐私权利**：补充真实处理者、保存期限、跨境/第三方处理、删除/更正/导出流程，并在收集定位前取得单独授权。
- **素材与肖像**：逐项核验图片、视频、Logo、字体和头像授权；已记录在 `docs/ASSET-SOURCES.md` 的许可也要结合商业用途复核。

## 当前原型边界

- `server/server.mjs` 是本地 Node + SQLite 原型，不是生产数据库或线上托管服务。
- 发布的项目、人才和需求默认 `pending_review`，只有审核通过后才可由公开列表接口返回。
- 前端演示列表和统计数字是示例内容；上线前应替换为真实、可追溯数据，或展示“暂无公开数据”。
- GitHub Pages 只承载静态前端，不能直接提供 `/api` 注册、登录和审核能力；需要单独部署 API 与数据库，并配置同源或严格 CORS。
