## 发布前检查

1. **逐个确认授权范围**：商业宣传、二次修改、地域、期限和是否包含肖像/商标。
2. **保留原始 URL、下载日期、许可页面快照和署名文本**；不要只保留图片文件。
3. 政府、园区、社区名称和 Logo 只能用于事实性信息标注，不能暗示合作、认证或官方背书。
4. 用户上传头像、项目图和联系方式必须取得必要授权；公开页默认不展示身份证、银行卡、手机号和私密联系方式。
5. 若来源许可无法确认，替换为自制图形、已购买素材或明确允许商用的素材，并将原图移出发布目录。
